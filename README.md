# Crypto Dash

This is an learning project app following the Udemy tutorial. Original repo is
[bradtraversy/crypto-dash](https://github.com/bradtraversy/crypto-dash)

React app to browse and search cryptocurrency information. This project uses the [CoinGecko API](https://www.coingecko.com/).

<img src='./public/screen.png' width='500' />

## Usage

Install dependencies

```bash
npm install
```

Run project

```bash
npm run dev
```

Build for production

```bash
npm run Build
```

Run production Build

```bash
npm run preview
```
